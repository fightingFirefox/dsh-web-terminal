# 下一阶段：终端槽位池与后台命令覆盖

状态：实施中（1.2.0 开发分支）。P3 设置与 P2 客户端已完成；P1 后台捕获卡在真机验证（宿主重启后读 `bg-debug.log` 定位）。

## 1. 现状与缺口

| 调用类型 | 当前行为 | 缺口 |
| --- | --- | --- |
| 前台 `pwsh` / `bash` | 主终端执行、跟随、ledger 记录 | 无（实测 402/402 覆盖） |
| `run_in_background: true` | `intercept.js:117` 直接放过，内置隐藏 shell 执行，只发 toast | **输出不可见**；近期样本 60/70 为后台命令 |
| 带 `sandbox_permissions` | 放过，保留审批流 | 不显示（可接受） |
| `terminal_send` / `terminal_read` / `live_terminal_*` | DSH 原生终端 | 不属于本插件 PTY（可接受） |
| 技能 / 外部 CLI / 脚本子进程 | 非本宿主 tool call | 无法覆盖 |

关键约束：内置后台命令在隐藏 shell 中执行，插件拿不到输出流。**显示后台输出必须由插件自己执行**，并接管 `job_output` / `job_kill` / `job_list`（只处理 `dsht-*` 命名空间，其余 `next()`）。

## 2. 槽位池模型

每会话固定数量逻辑槽，槽下挂真实 PTY 会话，槽内容可替换：

| 槽 | 数量 | 用途 |
| --- | --- | --- |
| 主终端 | 1（常驻） | 前台命令优先使用 |
| 后台终端 | 默认 2（1-4 可配） | 后台命令；空闲槽复用 |
| 用户终端 | 用户手动新建 | agent 不占用 |

分配规则：

1. 前台命令：主终端空闲 → 主终端；被占 → 空闲后台槽（换成交互壳）；都没有 → 未达上限则新建，已达则排队。
2. 后台命令：空闲后台槽 → 复用（旧内容进历史）；全忙且未达上限 → 新槽；达上限 → 回退内置执行 + toast。
3. 瞬时后台命令同样走槽；槽复用使其表现为「同一格内容刷新」，不新增终端。
4. 长命令结束：槽转空闲并保留；空闲槽超过 keep 值（默认 2）时回收最旧，其余进历史弹窗。

## 3. 切换与自动聚焦

面板内标签栏（不新增 sidebar 页）：`主终端 | 后台 1 ● | 后台 2 ✓ | 用户终端 | 历史`。

- 命令开始 → 自动聚焦其槽（本会话可见时）。
- 长任务回流：非当前槽命令运行 ≥ 8s 后结束 → 自动切回该槽一次（可关）。
- 手动选中后 20s 内不被自动聚焦打断。
- 徽标：运行中圆点、退出码、耗时；标题取命令首行。

## 4. 后台执行与 job 兼容

新增 `lib/host/bg-jobs.js`：

- `run()` → `registry.createCommandSession({ sessionId: root, command, cwd, group })`，登记 `dsht-<uuid>`，立即返回 `{kind:'background', jobId, cwd}`。
- 接管 `job_output` / `job_kill` / `job_list`；未命中命名空间原样 `next()`。
- 会话终态回填 exitCode / endedAt；宿主重启后 job 丢失，`job_output` 返回丢失说明，不伪造成功。
- `requiresConfinement` 时后台不接管，回退内置执行。

## 5. 回收与上限

- 可见槽上限默认 4；超出先回收「已结束最久」的槽。
- 已结束槽默认保留 2 个，其余关闭（内容在历史里）。
- 会话切走不杀后台命令；会话结束才终止其 job。

## 6. 风险

- `job_output` 语义必须贴近内置（运行中返回当前输出，结束返回完整 + exit code）。
- 后台输出受 `maxOutputBytes` / scrollback 限制。
- 并行前台命令（`Promise.all` 多命令）会占多槽，靠上限兜底。
- 子代理命令仍归属根会话，后台槽同样按根会话挂。

## 7. 实施分期

- **P1 宿主**：`agent-shell` 槽位化（key 加槽号）、`intercept` 分流、`bg-jobs`、job 工具接管。
- **P2 客户端**：面板内标签栏、槽切换、徽标、长任务回流。
- **P3 回收与设置**：槽上限、保留数、回流开关、后台接管开关。
- **P4 回归**：瞬时后台连发只占一格、30s 后台、两个并发长后台、前后台交叉、`job_output` 运行中/结束后、`job_kill`、重启后 job_output、子代理后台归属、跨会话不抢焦点。
